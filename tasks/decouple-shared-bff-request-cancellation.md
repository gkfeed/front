# Развязать отмену объединённых BFF-запросов

Status: proposed

Priority: P1

## Проблема

`BffResultCache` объединяет одновременные запросы по ключу. Общая upstream-загрузка использует `RequestExecutionContext` первого HTTP-клиента. Если этот клиент отключается, его `AbortSignal` отменяет загрузку и для остальных подписчиков.

## Что сделать

- Дать общей upstream-загрузке собственный execution context.
- Учитывать подписчиков каждой in-flight записи.
- Отменять ожидание отдельно для отключившегося клиента.
- Отменять upstream-загрузку после отключения всех подписчиков.
- Удалять in-flight запись после успеха, ошибки или полной отмены.

## Критерии приёмки

- Два клиента с одинаковым ключом используют одну upstream-загрузку.
- Отключение первого клиента не прерывает ответ второму.
- Upstream-загрузка отменяется, когда подписчиков больше нет.
- После ошибки или отмены следующий запрос запускает новую загрузку.
- Все сценарии покрыты тестами кеша и HTTP-маршрута.
